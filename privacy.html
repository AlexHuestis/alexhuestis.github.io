alex-os privacy policy

alex-os is used only by its owner, Alex Huestis, with his own Google account. No other users' data is accessed.

  • What it accesses: the owner's Gmail messages and Gmail filter settings, through the Gmail API with the owner's permission.
  • What it does: moves unwanted emails to Trash (never permanently deletes), creates filters that send chosen senders to Trash, and writes short summaries and draft replies. It never sends emails.
  • Third parties: to write summaries and drafts, the text of some emails is sent to Groq (an AI service). Emails from senders the owner marks as sensitive are never sent to any AI service. Summaries are delivered to the owner via Telegram. Data is not sold, shared for advertising, or used for any other purpose.
  • Storage: login tokens are stored on the owner's computer and as encrypted secrets in a private GitHub repository. Email content is not stored long-term.
  • Google API data: alex-os's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: access can be removed at any time at myaccount.google.com/permissions.
  • Contact: github.com/AlexHuestis
